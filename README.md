# AI Smart Recipe Maker

Репозиторій містить веб-застосунок «AI Smart Recipe Maker», який генерує персоналізовані рецепти, веде облік запасів, формує списки покупок і підтримує голосовий «кухонний» режим.

- Код застосунку: `ai-smart-recipe-maker/`
- Архітектура та технічний опис: `docs/architecture.md`
- Команди для запуску:
  ```bash
  cd ai-smart-recipe-maker
  npm install
  npm run dev
  ```
