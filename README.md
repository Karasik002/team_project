# AI Smart Recipe Maker

**AI Smart Recipe Maker** — персоналізований кулінарний помічник, що поєднує штучний інтелект, управління коморою та гейміфікацію. Достатньо ввести або надиктувати інгредієнти — система миттєво запропонує добірку рецептів з урахуванням ваших алергій, дієтичних вподобань, історії приготувань і вмісту комори.

## Основні можливості

- **Генератор рецептів**: голосове і текстове введення інгредієнтів, автоматичний пошук унікальних страв з фото, відео та порадами щодо подачі.
- **Харчова аналітика**: покрокові інструкції з голосовими підказками, підрахунок калорій та БЖВ, рекомендації згідно з фітнес-цілями.
- **Комора та закупівлі**: сканування штрих-кодів, контроль термінів придатності, управління залишками, списки покупок та економні рецепти.
- **Персоналізація профілю**: збереження алергій, дієт, улюблених кухонь, сторінка досягнень, історія приготувань.
- **Соціальні функції**: обмін рецептами, лайки, рейтинги, відгуки від інших користувачів.
- **Гейміфікація**: система балів XP, бейджі, кулінарні виклики та прогрес-статистика.
- **Асистент на кухні**: режим «вільні руки» з розпізнаванням голосових команд та озвученням кроків.

## Технології

- React 18 + TypeScript, Vite
- Material UI (MUI) 6 для UI-компонентів
- Zustand для стану, React Query для AI-запитів
- Luxon для роботи з датами, Recharts для візуалізації
- Web Speech API (розпізнавання мовлення та синтез)
- BarcodeDetector API (при наявності підтримки браузера)

## Запуск проєкту

```bash
npm install
npm run dev
```

За замовчуванням застосунок доступний на [http://localhost:5173](http://localhost:5173).

## Як користуватися

- **Головна**: введіть або надиктуйте інгредієнти, натисніть «Згенерувати рецепти», перегляньте картки з описом, інструкціями та відео. Додавайте відсутні інгредієнти до списку покупок в один клік.
- **Комора**: скануйте штрих-коди, додавайте товари, отримуйте попередження про терміни, створюйте економні рецепти зі залишків.
- **Профіль**: налаштовуйте ім’я, алергії, дієти, улюблені кухні, переглядайте улюблені страви та історію готування.
- **Спільнота**: публікуйте власні рецепти, залишайте відгуки й оцінки, підтримуйте авторів лайками.
- **Досягнення**: стежте за прогресом XP, відкривайте бейджі, виконуйте активні виклики.
- **Асистент**: запускайте режим «Режим асистента» з картки рецепта й керуйте процесом голосом («далі», «назад», «повтори», «стоп»).

## Примітки

- Для коректної роботи голосових функцій дозвольте доступ до мікрофона та використовуйте браузер із підтримкою Web Speech API (Chrome, Edge).
- Розпізнавання штрих-кодів доступне у браузерах з підтримкою API BarcodeDetector; інакше використовуйте ручне введення.
