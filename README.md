# 🍳 AI Smart Recipe Maker

Інтелектуальний кулінарний сайт, який використовує штучний інтелект для створення персоналізованих рецептів на основі наявних інгредієнтів.

![Next.js](https://img.shields.io/badge/Next.js-14.0-black)
![TypeScript](https://img.shields.io/badge/TypeScript-5.3-blue)
![TailwindCSS](https://img.shields.io/badge/TailwindCSS-3.4-38bdf8)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ Особливості

### 🎯 Основний функціонал
- **Генерація рецептів з AI** - Введіть інгредієнти голосом або текстом, отримайте унікальні рецепти
- **Персоналізація** - Налаштування під алергії, дієтичні уподобання (веган, кето, палео тощо)
- **Голосове управління** - Диктуйте інгредієнти та отримуйте голосові підказки під час готування
- **Детальна інформація** - Фото, відео-гайди, покрокові інструкції для кожного рецепту

### 📊 Харчування та здоров'я
- **Калькулятор БЖВ** - Автоматичний розрахунок калорій, білків, жирів і вуглеводів
- **Фітнес-цілі** - Встановлення та відстеження денних норм харчування
- **Рекомендації** - Персоналізовані поради для досягнення здоров'я

### 🏪 Управління продуктами
- **Комора** - Відстеження наявних продуктів з термінами придатності
- **Список покупок** - Автоматичне формування списку відсутніх інгредієнтів
- **Сканування штрих-кодів** - Швидке додавання продуктів (UI готовий, потребує інтеграції камери)
- **Сповіщення** - Нагадування про терміни придатності

### 🎮 Гейміфікація
- **Досягнення** - Відкривайте нагороди за кулінарні успіхи
- **Рівні та очки** - Прогресуйте та отримуйте бонуси
- **Виклики** - Щоденні та тижневі кулінарні завдання
- **Історія приготувань** - Відстежуйте свій прогрес

### 👥 Соціальні можливості
- **Обмін рецептами** - Діліться власними творіннями зі спільнотою
- **Відгуки та рейтинги** - Оцінюйте рецепти інших користувачів
- **Улюблене** - Зберігайте найкращі рецепти

### 🔊 Кухонний асистент
- **Режим асистента** - Покрокове голосове керівництво під час готування
- **Активний крок** - Виділення поточного етапу приготування
- **Таймери** - Автоматичні нагадування для кожного кроку

## 🚀 Швидкий старт

### Передумови
- Node.js 18+ 
- npm або yarn

### Встановлення

1. **Клонуйте репозиторій**
```bash
git clone <repository-url>
cd workspace
```

2. **Встановіть залежності**
```bash
npm install
```

3. **Запустіть сервер розробки**
```bash
npm run dev
```

4. **Відкрийте браузер**
Перейдіть за адресою [http://localhost:3000](http://localhost:3000)

## 📁 Структура проекту

```
workspace/
├── app/                          # Next.js App Router
│   ├── page.tsx                  # Головна сторінка з генерацією рецептів
│   ├── recipes/                  # Сторінки рецептів
│   │   ├── page.tsx              # Список популярних рецептів
│   │   └── [id]/page.tsx         # Детальна сторінка рецепту
│   ├── profile/page.tsx          # Профіль користувача
│   ├── pantry/page.tsx           # Комора (управління продуктами)
│   ├── shopping/page.tsx         # Список покупок
│   ├── achievements/page.tsx     # Досягнення та виклики
│   ├── layout.tsx                # Загальний layout
│   └── globals.css               # Глобальні стилі
├── components/                   # React компоненти
│   ├── Navigation.tsx            # Навігаційне меню
│   ├── IngredientInput.tsx       # Введення інгредієнтів з голосом
│   └── RecipeCard.tsx            # Картка рецепту
├── types/                        # TypeScript типи
│   └── index.ts                  # Основні типи даних
├── utils/                        # Утиліти
│   ├── recipeGenerator.ts        # AI генератор рецептів
│   ├── storage.ts                # LocalStorage обгортка
│   └── achievements.ts           # Система досягнень
└── package.json                  # Залежності проекту
```

## 🎨 Технології

- **Frontend Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: TailwindCSS
- **Icons**: Lucide React
- **Date Handling**: date-fns
- **State Management**: React Hooks + LocalStorage
- **Voice Recognition**: Web Speech API

## 🔧 Налаштування

### Персоналізація профілю

1. Перейдіть в розділ **Профіль**
2. Заповніть основну інформацію (ім'я, email)
3. Виберіть дієтичні уподобання
4. Додайте алергії та обмеження
5. Встановіть фітнес-цілі

### Використання голосового введення

1. Натисніть іконку мікрофона при введенні інгредієнтів
2. Дозвольте доступ до мікрофона в браузері
3. Чітко промовте назву інгредієнта
4. Система автоматично розпізнає та додасть його

### Режим кухонного асистента

1. Відкрийте детальну сторінку рецепту
2. Натисніть **"Почати готувати"**
3. Слідкуйте за виділеними кроками
4. Використовуйте кнопку "Озвучити крок" для голосових підказок

## 📱 Можливості браузера

- **Chrome/Edge**: Повна підтримка голосового введення (українська мова)
- **Firefox**: Часткова підтримка Web Speech API
- **Safari**: Обмежена підтримка голосових функцій
