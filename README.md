# AI Smart Recipe Maker

Персональний інтелектуальний кулінарний помічник, який генерує рецепти на основі наявних інгредієнтів, враховує алергії та дієтичні вподобання, керує запасами продуктів, відстежує калорійність і супроводжує процес приготування голосовими підказками.

## Основні можливості

- **AI-генерація меню**: введення або голосове надиктовування інгредієнтів та миттєве отримання добірки рецептів з фото, відео-гайдом, покроковою інструкцією, підрахунком БЖВ і порадами щодо подачі.
- **Персоналізація профілю**: зберігання алергій, дієт (веган, кето тощо), улюблених страв і фітнес-цілей для індивідуальних рекомендацій.
- **Розумна комора**: облік продуктів, сканування штрих-кодів (якщо підтримує браузер), нагадування про терміни придатності, автоматичне поповнення списку покупок та пропозиції економних страв із залишків.
- **Гейміфікація та соціум**: досягнення, тижневі виклики, загальний рейтинг рецептів, публікація власних ідей та взаємодія з іншими користувачами.
- **Асистент на кухні**: режим голосового помічника з короткими нагадуваннями, таймінгом і порадами з техніки безпеки.

## Стек технологій

- [Vite](https://vitejs.dev/) + React 18 + TypeScript
- Tailwind CSS для швидкого дизайнінгу інтерфейсу
- Zustand для легкого керування станом (профіль, комора, гейміфікація, асистент)
- React Hook Form для роботи з формами профілю
- React Query (готовий для інтеграції з реальним бекендом)

## Запуск проєкту

```bash
npm install
npm run dev
```

Доступ до застосунку: [http://localhost:5173](http://localhost:5173)

## Структура каталогу

- `src/pages` — основні сторінки застосунку (головна, комора, профіль, челенджі, спільнота, асистент)
- `src/store` — глобальні стани (користувач, комора, гейміфікація, асистент)
- `src/services/recipeEngine.ts` — модуль «AI», який симулює генерацію рецептів та рекомендацій
- `src/hooks` — віджет голосового введення та сканера штрих-кодів
- `src/utils` — прості утиліти (час, генерація ідентифікаторів)
