# AI Smart Recipe Maker

AI Smart Recipe Maker — це адаптивний веб-застосунок, що перетворює наявні інгредієнти на персоналізовані кулінарні пригоди. Вводьте або диктуйте продукти, зберігайте алергії та дієтичні вподобання, відстежуйте запаси, створюйте списки покупок, взаємодійте з іншими гурманами та отримуйте голосові підказки в «кухонному режимі».

## Основні можливості

- **AI-генерація рецептів**: миттєві страви з фото, відео та розрахунком БЖВ, що враховують історію приготувань, дієти й алергії.
- **Голосові сценарії**: введення інгредієнтів через Web Speech API та режим «Асистент на кухні» з озвучуванням кроків.
- **Профіль користувача**: дієтичні обмеження, алергії, фітнес-цілі, улюблені кухні, улюблені рецепти.
- **Керування запасами**: додавання вручну або за демо-штрих-кодами, контроль термінів придатності, підказки щодо використання залишків.
- **Список покупок**: автоматичне поповнення бракуючих інгредієнтів із рецептів та ручне керування.
- **Гейміфікація та спільнота**: виклики, досягнення, стрічка з рецептами користувачів, коментарі й вподобайки.

## Технологічний стек

- **Фронтенд**: React 19 + Vite + TypeScript
- **UI**: Tailwind CSS 3, власні компонентні примітиви, lucide-react для іконок
- **Стан**: Zustand (профіль, AI-рецепти, запаси, список покупок, гейміфікація, спільнота)
- **Дані**: локальне збереження через Zustand persist + мок-сервіси (`recipeEngine`, `nutritionDatabase`, `barcodeCatalog`)
- **Інші інструменти**: @tanstack/react-query (готовність до API), uuid, clsx

## Запуск проєкту

```bash
npm install
npm run dev
```

- Дев-сервер відкриється на `http://localhost:5173`.
- `npm run build` генерує продакшн-збірку в `dist/`.

## Структура

- `src/types` — типи доменних сутностей (рецепти, профіль, запаси тощо)
- `src/services` — AI та нутрітивні обчислення, генератор рецептів
- `src/stores` — Zustand-сховища (профіль, рецепти, запаси, покупки, гейміфікація, спільнота)
- `src/data` — демо-штрих-коди, шаблони рецептів, нутрітивна база, community feed
- `src/components` — UI-примітиви, інгредієнтний ввід, картки рецептів
- `src/routes` — сторінки та режими (`Dashboard`, `Recipes`, `Pantry`, `ShoppingList`, `Profile`, `Community`, `Challenges`, `KitchenAssistant`)
